# LifeInRussia

Small 3D narrative/simulation game built with Godot 4.

The project explores a day-by-day world where earlier choices and public decisions change later events, locations and NPC behavior.

## Development

Read before contributing:
- `AGENTS.md` — instructions for Codex/AI-assisted work
- `docs/WORKFLOW.md` — Git and collaboration workflow
- `docs/GAME_DESIGN.md` — current game concept
- `docs/ARCHITECTURE.md` — technical guardrails

## Branching

`main` should remain in a working state. Use short-lived task branches such as:
- `feature/...`
- `fix/...`
- `content/...`
- `chore/...`

## Engine

Godot 4.x, GDScript.
